# NORTH/FORM

Demonstração de uma loja virtual fictícia de roupas esportivas, criada com React, TypeScript e Vite. O projeto é apenas front-end: produtos, valores, imagens e interações são ilustrativos; não há servidor, autenticação, estoque nem processamento de pedidos.

## Executar localmente

Requisitos: Node.js 18+ e npm.

```bash
npm install
npm run dev
```

Abra o endereço local exibido pelo Vite no terminal. Para conferir a versão de produção:

```bash
npm run build
npm run preview
```

## O que está demonstrado

- Home com destaque da coleção, categorias, produtos, editorial e rodapé.
- Catálogo com filtros interativos de categoria, tamanho e cor, além de ordenação por preço.
- Página de produto com seleção de tamanho e ação demonstrativa de adicionar à sacola.
- Sacola com quantidades, remoção de itens, subtotal e resumo fictício.
- Navegação adaptada para telas pequenas, estados vazios e interações de interface.

As imagens de inspiração de produto são carregadas do Unsplash e as fontes do Google Fonts; não há integração com APIs de produtos.
